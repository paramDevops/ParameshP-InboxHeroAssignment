# Assignment 07 Submission Checklist

Use this checklist before submitting.

## Core functionality
- [ ] Inbox is loaded and processed.
- [ ] Every message receives one disposition.
- [ ] Messages are not left undecided.
- [ ] Replies are grounded in cited earlier messages.
- [ ] Irreversible actions are gated.
- [ ] Preference state persists across restarts.
- [ ] Hostile embedded instructions are refused.
- [ ] Dashboard or summary output is generated.

## Project quality
- [ ] Code runs from the project root.
- [ ] Dependencies are clear and minimal.
- [ ] Logs or traces are produced when relevant.
- [ ] README or report explains design choices.
- [ ] Final answer is concise and evidence-based.

## Final report
- [ ] Explain the system architecture.
- [ ] Explain how the gate prevents dangerous actions.
- [ ] Explain privacy and safety handling.
- [ ] Explain how memory survives restarts.
- [ ] Mention limitations and risks.
